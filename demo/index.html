pure·css foundation

@keenmate/pure-css · v1.0.0-rc04

One theming layer.
Every surface.

The KeenMate CSS foundation — a --base-* theming contract, a container-query flexbox grid, and a full utility layer, compiled from pure SCSS. No JS. No runtime. Override the variables once and the whole system re-themes.

Zero runtime 10px rem base 6 composable layers Container-query grid MIT

01 — install

Drop it in.

Import the full bundle, or cherry-pick a single layer through the package exports map. dist/ is committed, so consumers vendor the built CSS with no Sass toolchain. 

# from npm
npm install @keenmate/pure-css

# the full bundle
@import "@keenmate/pure-css/css";
<!-- or a single layer -->
<link rel="stylesheet"
      href="…/pure-css/reboot">
<link rel="stylesheet"
      href="…/pure-css/utilities">

02 — the layers

Six artifacts, one contract.

Each source entry compiles to exactly one dist/css/*.css. Take the lot, or just the pieces you need.

base · 5.7K

The --base-* + --pc-* defaults at :root.
reboot · 1.2K

10px base + box-sizing reset + element normalize.
grid · 29K

.pc-row / .pc-col-* flexbox grid.
utilities · 35K

Spacing, flex, display, sizing, borders, text.
scrollbars · 0.7K

Thin scrollbars, coloured from the theme.
pure-css · 71K

Everything above, one common bundle.

Everything on this site is built with pure-css itself — the tiles above are a live .pc-row / .pc-col-* grid, the accent text is .text-primary, the spacing is the utility scale.

03 — the idea

Change the variables, not the CSS.

A theme is nothing more than a set of --base-* values. Because pure-admin-core, every KeenMate component and this site all read the same tokens, one override block re-themes them all at once. See it move on the Theming page.
