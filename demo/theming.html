02 — two layers, honestly

--base-* authors, --pc-* runs.

pure-css compiles $base-* SCSS into two runtime layers. Knowing which is which is the whole trick:

--pc-* · runtime contract

The tokens pure-css's own utilities, grid and reboot actually read. Override these to re-theme the framework's output live — that's what the sliders above do.

--base-* · authoring source

The compile-time source of truth that KeenMate web components read directly. One value bridges to runtime: --pc-border-color: var(--base-border-color).

/* re-theme every pure-css surface at once */
:root {
  --pc-accent: #10b981;
  --pc-main-bg: #f6fbf8;
  --base-border-color: #cfe8dc; /* → --pc-border-color */
}
